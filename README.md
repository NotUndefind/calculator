
# 🧮 Calculatrice React

Ce projet est une **calculatrice interactive** développée avec **React**, **TypeScript**, **Vite** et **Tailwind CSS**.

---

## 🚀 Fonctionnalités

- ✅ Calcul dynamique pendant la saisie
- ➕➖✖️➗ Opérations de base : addition, soustraction, multiplication, division
- 🔁 Bouton `±` pour inverser le signe du dernier nombre
- 📉 Bouton `%` pour transformer un nombre en pourcentage
- 🧼 Bouton `AC` pour réinitialiser la calculatrice
- 🟰 Bouton `=` pour valider le calcul
- 🎨 Interface responsive et design épuré avec TailwindCSS

---

## ⚙️ Stack technique

- [React](https://reactjs.org/)
- [TypeScript](https://www.typescriptlang.org/)
- [Vite](https://vitejs.dev/)
- [Tailwind CSS](https://tailwindcss.com/)

---

## 🛠 Installation

```bash
# Clone le projet
git clone https://github.com/JulesBourin/Calculatrice.git
cd Calculatrice

# Installe les dépendances
npm install

# Démarre le serveur de dev
npm run dev
```
